Guia de Instalação no Notebook — Windows

📋 Resumo: 5 programas para instalar (UMA VEZ no PC)

#ProgramaComo instalar
1Python 3.11+Baixa do site → dois cliques → marca "Add to PATH"
2Node.js (LTS)Baixa do site → dois cliques → Next, Install
3MongoDB CommunityBaixa do site → marca "Install as Service"
4MongoDB Database ToolsBaixa do site → Next, Install (para backup)
5YarnNo CMD: npm install -g yarn
⚠️ Os 4 primeiros programas são instalados de qualquer pasta — você só dá dois cliques no instalador baixado. O Yarn (item 5) é o único que usa o CMD, e o comando funciona de qualquer pasta também.

🐍 1. Python

1 Abra: https://www.python.org/downloads/
2 Clique em "Download Python 3.x" (botão amarelo)
3 Dois cliques no arquivo .exe baixado
4 ⚠️ MUITO IMPORTANTE: marque a caixa "Add Python to PATH"
5 Clique em "Install Now" e aguarde

🟢 2. Node.js

1 Abra: https://nodejs.org/
2 Clique no botão verde "LTS"
3 Dois cliques no arquivo .msi baixado
4 Next → Next → Install (não precisa marcar nada extra)

🍃 3. MongoDB Community

1 Abra: https://www.mongodb.com/try/download/community
2 Escolha: Current version, Windows, MSI → clique "Download"
3 Dois cliques no arquivo baixado
4 Escolha "Complete"
5 ⚠️ Marque "Install MongoDB as a Service"
6 Install

🛠️ 4. MongoDB Database Tools (para backup)

1 Abra: https://www.mongodb.com/try/download/database-tools
2 Escolha: Windows, MSI → Download
3 Dois cliques no arquivo → Next → Install

⌨️ 5. Yarn (no CMD)

1 Aperte Windows + R → digite cmd → Enter
2 Cole este comando e aperte Enter:
npm install -g yarn
3 Aguarde aparecer "success"

✅ Verificar se tudo deu certo

Reinicie o PC. Depois abra o CMD e digite cada comando abaixo (um por vez):

python --version
node --version
yarn --version
mongod --version
✅ Se cada um responder com um número de versão (ex: Python 3.12.0), está tudo instalado certo!

📁 Onde colocar a pasta do sistema?

Recomendado: C:\MM-Confeitaria\

Evite: pastas dentro do OneDrive ou Google Drive (sincronização atrapalha)
